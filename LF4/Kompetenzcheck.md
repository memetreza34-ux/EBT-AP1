# LF4 – Kompetenzcheck und tatsächlicher Lernfortschritt

**Aktueller Fokus:** PC-Hardware und Stecker/Anschlüsse; danach Netze und die weiteren offiziellen LF4-Kompetenzen.  
**Stand bei Einrichtung:** alle Aufgaben *offen*, nichts als bestanden behauptet.  
**Ohne feste Tage:** Nach jeder Sitzung hier die letzte bearbeitete Lektion und die nächste offene Frage notieren.

## Statusregel

- **☐ Offen** = noch nicht bearbeitet
- **🟡 Mit Hilfe** = Erklärung verstanden, ohne Hilfe erneut überprüfen
- **🟢 Sicher** = eigenständig richtig erklärt + Transferaufgabe gelöst
- **🔴 Wiederholen** = falsch oder unklar; mit neuem Beispiel erklären und erneut prüfen

## Lernmodule – Teilziele

### 1. PC-Hardware
- [ ] EVA mit Beispielen erklären.
- [ ] CPU, RAM, SSD/HDD, Mainboard, Netzteil, GPU korrekt erkennen und zuordnen.
- [ ] Datei öffnen, bearbeiten und speichern technisch erklären.
- [ ] Flüchtig vs. nichtflüchtig unterscheiden.
- [ ] UEFI, Betriebssystem, Treiber auseinanderhalten.
- [ ] Passende PC-Ausstattung anhand eines Auftrags auswählen.

### 2. Stecker/Schnittstellen (besonders intensiv)
- [ ] USB-A, USB-B, USB-C an echten Bildern unterscheiden.
- [ ] HDMI, DisplayPort, VGA, DVI am Foto unterscheiden.
- [ ] Ethernet-8P8C, Audio-Klinke, DE-9/RS-232 erkennen.
- [ ] SATA-Daten-, SATA-Stromstecker, M.2, PCIe, RAM-DIMM zuordnen.
- [ ] Bauform, Schnittstelle, Protokoll unterscheiden.
- [ ] Bei USB-C Form und unterstützte Funktionen nicht verwechseln.
- [ ] Mindestens 12 zufällig gemischte Anschlussbilder **ohne Beschriftung** korrekt benennen.

### 3. Daten/Zahlen
- [ ] Bit/Byte umrechnen, b vs. B.
- [ ] Dezimal ↔ Binär, Binär ↔ Hex.
- [ ] SI kB/MB/GB von IEC KiB/MiB/GiB unterscheiden.
- [ ] Datenrate und Übertragungszeit mit richtigen Einheiten berechnen.

### 4. Netzwerke
- [ ] Router, Switch, Access Point, Netzwerkkarte unterscheiden.
- [ ] IP, MAC, Gateway, Netzmaske erklären.
- [ ] DHCP vs. DNS erklären.
- [ ] Gleiches /24-Subnetz erkennen.
- [ ] TCP, UDP, LAN, WLAN, Ethernet grundsätzlich erklären.
- [ ] Fehler eingrenzen: Link → IP → Gateway → DNS.

### 5. Software
- [ ] UEFI, OS, Treiber, Standard-/Fachsoftware unterscheiden.
- [ ] Installation/Kompatibilität nach Anforderungen planen.
- [ ] Datei, Ordner, Dateisystem, Backup unterscheiden.

### 6. Sicherheit/Recht
- [ ] Vertraulichkeit, Integrität, Verfügbarkeit erklären.
- [ ] Datenschutz vs. Datensicherheit unterscheiden.
- [ ] Backup und Wiederherstellung planen; RAID ≠ Backup.
- [ ] Zugriffsrechte/Updates/Verschlüsselung benennen.
- [ ] Grundfragen zu Lizenz-/Urheberrecht beantworten.

### 7. Auftrag/Auswahl
- [ ] Lastenheft vs. Pflichtenheft mit Beispiel.
- [ ] Muss/Soll/Kann-Anforderungen unterscheiden.
- [ ] Kompatibilität, Wirtschaftlichkeit, Nachhaltigkeit prüfen.
- [ ] Ergonomie berücksichtigen.
- [ ] Nettokosten, Zeit und Umsatzsteuer in Aufgabe rechnen.

### 8. Fehlersuche/Übergabe
- [ ] Symptome → Hypothesen → gezielter Test → Nachprüfung.
- [ ] Drucker-/Netzwerk-/Startprobleme systematisch eingrenzen.
- [ ] Funktions-/Abnahmeprüfung entlang Pflichtenheft.
- [ ] Prüf- und Übergabeprotokoll erstellen.
