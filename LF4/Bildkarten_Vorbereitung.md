# LF4 – Vorbereitung für echte Anschluss- und Hardwarebilder

**Ziel:** Du sollst Anschlüsse **optisch sicher erkennen**, nicht nur ihre Namen lesen. Deshalb enthält die spätere Übung Bildkarten mit wirklich passender Ansicht.

## Fotoanforderungen

1. Echte, scharfe **Nahaufnahme** eines Anschlusses; keine futuristische KI-Hardware.
2. Front-/Rückseite oder Mainboard-Ausschnitt, idealerweise **eine klare Schnittstelle pro Bild**.
3. **Zwei Varianten pro Typ**, damit man nicht eine einzelne Produktaufnahme auswendig lernt.
4. Für den Test die Lösung **nicht als Beschriftung** direkt auf das Bild setzen.
5. Nach dem Raten: richtiger Name + zwei Formmerkmale + typischer Verwendungszweck.
6. Bildrechte, Bildquelle und mögliche Nachbearbeitung dokumentieren; nur Material mit passender Nutzungserlaubnis ins Repository hochladen.

## Pflichtkarten

| Kartengruppe | Anschluss/Komponente | Verwechslung |
|---|---|---|
| USB | USB-A / USB-B / USB-C | Steckerform und USB-Version |
| Video | HDMI / DisplayPort / VGA / DVI | digital/analog und äußere Form |
| Netzwerk/Audio | Ethernet-8P8C / 3,5-mm-Klinke | Einsatzgebiet |
| Ältere/Industrie | PS/2 / RS-232 DE-9 | nicht als USB oder VGA benennen |
| Intern | SATA-Daten / SATA-Strom | Daten oder Energie? |
| Intern | M.2 / PCIe / DIMM | SSD-Modul, Erweiterungssteckplatz oder Arbeitsspeicher |
| Hardware | CPU / Mainboard / RAM / SSD / HDD / Netzteil / GPU | Aufgabe statt Aussehen erraten |

**Ablauf pro Karte:** zuerst Foto → eigener Name → Funktion → Lösung → Fehlerursache notieren.  
**Status:** Bilder **noch nicht hinzugefügt**, weil echte Fotos und Quellen zuerst geprüft werden müssen. Dieses Dokument bereitet die Fotosammlung und den Erkennungstest vor.
