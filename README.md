# EBT – Vorbereitung auf die Abschlussprüfung Teil 1

**Beruf:** Elektroniker/-in für Betriebstechnik (Industrie/IHK)  
**Start:** 12.10.2026  
**Aktueller Schwerpunkt:** Lernfeld 2 – Elektrische Installationen planen und ausführen  
**Ziel:** In fünf intensiven Lerntagen die Inhalte von LF2 systematisch erarbeiten und mit anwendungsnahen Aufgaben sichern.

> Hinweis: Die fünf Tage ersetzen nicht die 80 Unterrichtsstunden des Lernfelds. Die AP1 fragt Inhalte mehrerer Lernfelder und betrieblicher Ausbildung ab. Dieses Projekt ist eine gezielte, vertiefbare Vorbereitung, keine Zusage, dass jede mögliche Prüfungsfrage abgedeckt ist.

## Einstieg

1. [Offizielle Lernziele und AP1-Abgrenzung](01_Offizielle_Grundlagen.md) lesen.
2. [Fünf-Tage-Lernplan](02_Lernplan_5_Tage.md) verfolgen.
3. Jeden Tag die entsprechende Lerneinheit durcharbeiten, Aufgaben **ohne Lösung** beantworten und Fehler besprechen.
4. Ergebnisse im [Lernfortschritt](Lernfortschritt.md) dokumentieren.
5. Abschließend die [LF2-AP1-Simulation](LF2/Tag_5_AP1_Simulation.md) bearbeiten.

## Die fünf Lerneinheiten

| Tag | Datei | Schwerpunkt |
|---|---|---|
| Montag | [Tag 1](LF2/Tag_1_Schaltungen_und_Plaene.md) | Installationsschaltungen, Schalterwahl, Pläne |
| Dienstag | [Tag 2](LF2/Tag_2_Leitungen_und_Schutz.md) | Leitungen, Netzsysteme, Überstrom-, Fehlerstromschutz |
| Mittwoch | [Tag 3](LF2/Tag_3_Bemessung_und_Kosten.md) | Leistung, Strom, Leitungsbemessung, Spannungsfall, Angebot |
| Donnerstag | [Tag 4](LF2/Tag_4_Pruefung_und_Inbetriebnahme.md) | Sicherheitsregeln, Erstprüfung, Fehlersuche, Dokumentation |
| Freitag | [Tag 5](LF2/Tag_5_AP1_Simulation.md) | Prüfungsnaher Gesamtauftrag, schriftliche Simulation |

## Lernmethode

**Verstehen → Beispiel → selbst lösen → korrigieren → ohne Hilfe wiederholen.**  
Nicht alles ablesen: Schaltpläne auf Papier zeichnen, Rechenwege mit Einheiten schreiben, Entscheidungen begründen. Bei unter 80 % in einem Selbsttest den Abschnitt noch einmal wiederholen.

**Sicherheit:** Praktische Arbeiten an Elektroinstallationen ausschließlich im erlaubten Ausbildungsrahmen, unter fachlicher Aufsicht, sicher freigeschaltet. Aufgaben in diesem Repository können auch vollständig theoretisch bearbeitet werden.
